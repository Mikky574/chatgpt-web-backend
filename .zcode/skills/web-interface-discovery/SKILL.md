把用户授权的一项网页操作收束成可调用能力。先证明页面如何触发、请求属于谁、结果如何完成，再决定是否能脱离页面调用。不要默认存在稳定API，不把观察到接口地址或HTTP 200当作业务调用成功。

## 开始前确定边界

从任务和当前会话确定目标站点、具体动作、当前账号/租户、允许产生的副作用、预期结果及运行环境。已有授权继续有效；普通只读观察不另设审批。写入测试优先使用用户授权的合成对象；不能因“探索接口”就执行真实审批、支付、删除、发布或扩大访问权限。

有现成连接器、官方文档、站点维护方提供的API或内部源码接口定义时先利用它们，网络观察用来补足运行证据。没有接口文档时，从一项确定的页面动作开始，不扫描未知主机、目录或批量猜测接口。

内部页面的原始内容、请求体、响应体、完整HAR及账号信息默认留在内部环境。不得为请外部模型分析而上传这些资料。可披露的接口结构与故障摘要也须符合用户的披露约束。

## 执行范式

1. **锁定现场。** 精确选定已有标签页和登录上下文。不要取第一个账号、第一条同名任务或第一个输入框。先读页面状态，保护草稿；有多个候选时停止猜测。后台创建标签页时核对返回的target身份，不主动激活窗口。
2. **拆解动作。** 写下“业务目标 → 页面入口/项目 → 控件 → 一次触发 → 提交已确认 → 业务结果”。定位优先使用语义角色、标签、稳定属性，再考虑结构选择器。控件被遮挡先检查实际状态，可用其正常键盘操作；不盲目force click。按钮点击完成不等于服务端接收。
3. **先监听再触发。** 在一次有授权的合成/只读动作前注册监听。将动作前状态、公开测试标识（业务允许时）、请求、响应和结果关联起来，排除埋点、预取、自动保存等旁支。不把任意时间相近的请求认作主接口。具体做法见[发现与证据](references/discovery.md)。
4. **建立接口契约。** 记录已观察的方法、路径模板、请求字段类型、认证依赖、响应/流协议、业务身份及完成信号。每个结论标记“已观察、推断、未验证”。没有观察到的必要字段留未知，不照搬其他网站的私有协议。用[记录模板](assets/interface-record.md)交付可复查证据。
5. **验证认证与调用层级。** 区分浏览器已登录、业务有权访问、CSRF/请求证明、租户/项目归属。只记录凭据的存在、类型、作用域和有效状态，不记录值。先看[认证与传输](references/auth-and-transport.md)，再做一项最小对照；403不能单独证明令牌过期。保留会话的真实权限，不伪造验证证明或扩大账号权限。
6. **实现适配器。** 根据证据选择官方API、独立HTTP、浏览器同源请求或页面操作。把任务、上下文、请求、异步结果、下载与故障恢复分开；具体约定见[适配器与恢复](references/adapter-and-recovery.md)。没有证明可用的传输层不得作为默认。保留已测通路径，明确依赖哪些浏览器步骤。
7. **做反例验证。** 至少覆盖该操作实际存在的风险：提交未送达/结果不确定、身份不符、超时、重复请求、明确完成与失败；需要多任务、项目、流式或下载时再补相应测试。不为简单只读操作强加整套队列系统。行为测试与现场实测分开报告。

## 凭据与信息处理

Cookie、Authorization、API Key、密码、OAuth code、访问/刷新令牌、CSRF值和带签名下载URL不能写进skill、示例、日志、截图交付或Git。不要读取凭据文件来整理摘要。不要直接复制“Copy as cURL”或未脱敏HAR作为实现材料；它们常含会话凭据与私有业务内容。

在已授权环境中，运行时可按站点正常机制使用凭据，但观测输出只应包含必要元数据。浏览器Cookie保留在浏览器；独立服务身份使用本机秘密存储或组织凭据服务，交互时不要求用户把秘密发到聊天。单独实现的刷新流程必须有已验证的站点契约、轮换保存和失败停止规则，不能从发现refresh字段就推断会话可无限续期。

## 可复用观测工具

有Node.js和当前工具目录可解析的playwright-core时，可运行本目录[scripts/observe-network.mjs](scripts/observe-network.mjs)：

```text
node <skill目录>/scripts/observe-network.mjs --cdp http://127.0.0.1:9222 --page-url https://internal.example/workbench --duration-ms 20000 --output records/web-discovery/observation.json
```

这是被动监听：只绑定精确URL的唯一已有标签页，不新建或导航页面，不点击，不重放请求。监听期间由用户或已授权的页面工具触发目标动作。脚本只输出本页同源的请求元数据；它不分析认证头、Cookie、请求体或响应体，也不证明接口关联或可直接调用。没有网络事件可能只是页面已空闲、请求由Worker发出或用了其他源，不能判定服务故障。

脚本按常见模式隐藏路径中的ID及所有查询值，不能保证路径名称不含业务敏感信息；报告默认仅本地保留。具体参数、覆盖限制与后续分析见[发现与证据](references/discovery.md)。若当前浏览器工具不允许CDP/本机脚本，使用其受支持的网络面板或站点工具，不另起未经允许的控制通道。

## 交付与停止条件

交付实际可调用的最小入口、接口记录、状态/恢复规则、测试结论和仍未验证的部分。明确目前属于哪层：仅网页触发、浏览器内请求、独立后台HTTP或官方API。未实现的项目操作、认证刷新、逐token流、取消或恢复不能写成已经支持。

验证码、权限不足、账号歧义、协议证明不足时停止相应动作，给出可执行的下一步；不要用无限刷新、换账号、新建对象或盲目重发来掩盖错误。对话失效后新建属于业务策略，必须有用户授权且可见地记录上下文丢失，不对所有内部业务照搬这一策略。
