# 从页面动作发现接口

## 一次受控观测

以内部“生成合成报表”为例，先确认目标是测试对象，且允许产生一次报表。记录当前租户、项目、页面与操作前业务状态，凭据不进入记录。打开Network监听后输入合成名称，例如`demo-report-<本地生成标识>`；只触发一次“生成”。禁止为了抓包反复点击。

按因果关系分类，而不是只看路径是否像API：

| 观察 | 候选角色 | 还要验证 |
| --- | --- | --- |
| GET加载页面数据、权限或配置 | 准备/查询 | 是否缓存、是否必须先执行 |
| POST返回202与job引用 | 提交异步工作 | 引用是否属于本次动作，是否真正受理 |
| GET轮询同一job | 进度/结果 | 状态机及终态，结果与输入对象是否相符 |
| text/event-stream | SSE流 | 事件类型、业务ID、完成/错误事件 |
| WebSocket连接/帧 | 双向通道 | 初始化、订阅、关联ID、应答及断线重连语义 |
| 下载响应或短期URL | 获取产物 | 结果对象、权限、过期与实际文件内容 |

一次成功样本只建立候选契约。再做一次有意义的对照：改变一个合成输入、换一个测试项目或查询相同job。不要把写操作的重放当成默认对照。对照前明确是否会创建第二个对象。

## 如何关联主请求

- 把监听安装在操作之前；记录时间线、发起页面/帧、方法、路径、状态、Content-Type与请求链。SPA操作可能先prepare再submit，再通过另一通道取结果。
- 测试标识只能放在业务允许的字段中；不能私自给签名请求加字段或给真实内容加标识。
- 存在业务request_id、job_id、conversation_id或document_id时，用它们关联；对外报告使用别名，内部映射单独保留。
- 若需读取请求/响应结构，只检查已确认的测试请求，优先输出字段名与类型。合成值也要确认不会混入真实Cookie、账号或服务返回的业务数据。
- 主接口应能解释“控件动作 → 业务状态变化 → 当前对象结果”。埋点成功、消息回显、请求准备完成不能替代业务成功。
- 浏览器Worker、跨源iframe和WebSocket可能不在page级XHR监听中。先说明观测缺口，按授权扩展到context/Worker/对应帧，而不是宣布“没有接口”。

## 观测脚本

`observe-network.mjs`只记录指定页面同源请求的元数据以及WebSocket连接元数据，不读取WebSocket帧。URL按精确字符串选择，匹配多个页面或找不到时失败，不自动开页。需要观察另一个已授权源时另做明确配置，脚本不会捕获所有第三方请求。

依赖从当前工作目录解析。可在已有包含playwright-core的工具工程中运行；没有依赖时，在独立工具目录按组织软件安装规则安装，再从该目录运行脚本，不要求修改业务工程。它不需要下载新的浏览器。

参数：

| 参数 | 约定 |
| --- | --- |
| --cdp | 已授权的本机http/ws调试地址，只接受loopback |
| --page-url | 唯一已有页面的完整URL；尽量选择不带秘密查询参数的页面 |
| --duration-ms | 100..60000，默认20000；监听期间手动或用授权工具触发动作 |
| --output | 本地JSON输出路径，要求不存在；不覆盖已有证据 |

最多记录300项，多余项标记truncated。脚本不保存主机名、查询值、头或正文；常见UUID、长ID、邮箱和令牌形态路径段被替换。短名字、字段名、业务路径仍可能敏感。不要自动向外部模型发送原始观测文件。

脚本不是网络录像。它不能还原所有认证、流式内容或业务ID，也不能证明任一请求由某个按钮触发；这些需要上述受控动作及后续证据补足。

## 流式协议的确认

SSE按UTF-8增量解码并缓存跨chunk残片，按空行组装事件；处理CRLF、多个data行、注释心跳和event/id字段。网络chunk不等于一个JSON事件。仅在已确认的测试流中解析payload。

逐项确认：初始化/ACK、业务ID、文本增量或补丁、完整结果、用量、业务错误、完成信号。补丁协议需要按路径/操作维护状态，不能把每个data简单拼接。推理片段、输入回显或进度提示不能充当最终答案。

结束条件同时考虑业务终态与身份关联。连接关闭、200、字数稳定、前端主动abort和`[DONE]`都需结合该站点实际契约解释；没有明确完成信号时返回unknown/incomplete。断线后用原job/消息ID查询恢复，不重发提交请求。

## 只检查必要的前端代码

当用户允许读取内部前端源码时，搜索已观察到的路由、调用封装、CSRF处理、状态枚举或流解码器，验证候选契约。不要遍历密钥文件或把整份bundle发送到外部模型。压缩代码能说明前端如何构造请求，不能单独证明当前账号具有权限或该接口可脱离浏览器运行。
