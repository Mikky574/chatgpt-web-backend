# 主控手与操作手协作

入口技能：项目的 .zcode/skills/controller-operator/SKILL.md（此目录只是当前工具的技能发现路径，角色定义不绑定工具）。

使用方式：$controller-operator 帮我完成：你的任务。

主控手负责需求决策与验收建议，操作手负责本地分析、实施、测试和发起咨询。两者维护各自上下文，消息不传模型或产品身份。用户始终可在操作手对话补充需求。

调用适配器由 role-collaboration.json 选择，缺省读取 role-collaboration.example.json。当前适配器仍连接现有网页服务；更换模型需提供同协议适配器，不是改名称就能接通。

## 披露内容

允许经检查的项目相对结构、模块关系、文件作用和行为概括。例如 src/auth/、tests/，以及“配置目录中的凭据文件用于运行时鉴权”。敏感目录名称替换为占位符，不传绝对路径或真实用户名。

禁止凭据值、Cookie、令牌、私钥、客户数据、未经批准的源码及原始日志。内部摘要仍须符合组织披露规则。consult-controller.mjs 对结构化字段、长度、路径及部分凭据格式做校验；不能识别所有敏感值，当前不是不可绕过的安全网关。

## 当前演示

操作手已实际咨询主控、独立实现分页函数并运行16项测试，全部通过。随后仅以摘要回报同一主控对话，复核读取出现超时，操作手使用原ID恢复，不重复提交；复核未成功返回前不能声称完整验收闭环已经结束。
